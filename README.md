# PR Radar — `vllm-project/vllm`

Static snapshot built from **7,521 open PRs** and **640 dependency stacks**.

- `/overview` — Risk summary, triage breakdown, reviewer queues
- `/dag` — Dependency stacks and merge order
- `/collisions` — Contended hotspot files and live merge races
- `/triage` — 6-column triage Kanban board
- `/reviewers` — Reviewer pending queue & unanswered wait time
- `/simulator` — Merge impact & rebase hazard simulator
